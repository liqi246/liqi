# 营销线索转化分析

> **一句话概括**：基于某机构真实广告投放线索数据，构建了从“线索获取→有效沟通→客户分层”的完整分析框架，定位了客服触达瓶颈，并输出了渠道优化与销售跟单效率提升建议。

---

##  项目背景

线上广告投放（信息流、在线咨询）是核心获客渠道，但大量线索在分配后未能被有效跟进，导致投放预算浪费。

本项目以某机构2026年7月的 **一个月某一平台的733条真实脱敏线索** 为样本，对其投放指标进行分析并给出建议
- 诊断当前线索转化漏斗的健康度
- 定位销售跟单效率差异
- 评估不同广告单元的线索质量
- 输出可落地的业务建议

##  分析框架

### 1. 数据清洗
- 过滤关键列缺失的无效记录
- 拆分复合字段（`线索标签` → `标签_状态` + `标签_等级`）
- 映射离散状态为有序漏斗阶段（`通话状态` → `漏斗阶段`）

### 2. 全局转化漏斗
- 统计各阶段线索数量与占比
- 定位核心瓶颈：**近64.8%线索停留在"待联系"，有效沟通率不足21%**

### 3. 客户质量分层
- 基于 A/B/C/D 等级进行客户价值分层
- 识别高价值线索（A类/B类）的来源特征

### 4. 多维度下钻分析
- **销售人效**：各客服的线索分配量、触达率对比
- **广告单元效果**：各投放单元的有效沟通率与高质线索占比
- **地域分布**：各城市线索量与质量差异

---

##  核心发现

1. **客服触达是最大瓶颈**：75% 的线索停留在"待联系"或"未接通"阶段，仅 21% 进入有效沟通。
2. **销售人效差异显著**：部分销售触达率明显低于团队平均水平，存在跟单流程优化空间。
3. **高质量线索集中**：A/B 类线索集中在特定广告单元，建议优化投放策略，将预算向高质单元倾斜。
